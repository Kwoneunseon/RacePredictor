## 다음 세션: 모델 성능 점검 계획

### 점검 항목

1. **백테스트 재실행**
   - 최근 1~3개월 경주 데이터로 Precision@1, NDCG@3, 연승 적중률 측정
   - 현재 `TOP3_PROB_THRESHOLD=0.65`의 실제 정밀도 확인

2. **연승 추천 기준 재검토**
   - 백테스트상 80% 달성했다는 `0.65` 임계값이 실제 예측에서도 유효한지 확인
   - 오늘 케이스: top3_prob=0.676인데 실제 착9위 → 과신 가능성

3. **피처 중요도 분석**
   - 어떤 피처가 예측에 가장 크게 기여하는지 확인
   - 최근 성적 피처(`prev_5_avg_rank`, `recent_rank_trend`) 유효성 점검

4. **모델 리랭킹 로직 검토**
   - LambdaRank 블렌딩(0.5) 비율이 적절한지 확인
   - Softmax temperature(0.3)이 너무 뾰족한 분포를 만드는지 확인

5. **부산 final_rank 업데이트 방식 확인**
   - 현재 부산은 ScoreInfo win_odds만 수집되고 final_rank가 업데이트 안 됨
   - `update-results` 명령어에서 부산 최종순위 수집 경로 점검

## 발견/수정한 버그 (재발 방지용으로 코드는 유지)

1. **말 통산 성적 필드명 오류**: 계획서 가정(`ord1CntT`/`ord1CntY`/`rcCntT`/`rcCntY`)이 실제 API와 달랐음. 진짜 필드는 `hrOrd1CntT`/`hrRcCntT`(통산만 존재, 최근1년 필드 없음). 기수/조교사 필드는 계획서 가정이 맞았음.
2. **`_join_section_records` 컬럼 충돌**: `horse_section_records`도 `race_distance`/`horse_id` 컬럼을 가져 `merge_asof`가 `_x`/`_y` 접미사를 붙이며 원본 컬럼이 사라짐 → `dropna` 단계에서 대량 행 손실.
3. **같은 메서드 인덱스 충돌**: `merge_asof`가 결과에 새 `RangeIndex`를 부여, 말별 그룹 병합 후 concat 시 인덱스 중복 → `sort_index()`가 서로 다른 말의 행을 뒤섞음. 인기마 기준선이 20.8%→19.4%로 흔들린 증상으로 발견.
4. **PostgREST 임베디드 조인 실패**: `race_entry_detail`에 FK 제약이 없어 `races(...)/race_entries(...)` 임베딩 조인이 `PGRST200`으로 실패 → 수동 2단계 조회로 수정.
5. **통과순위/구간기록의 0값 함정**: 짧은 거리에서 0은 "미해당"이지 실제 값이 아님 — 무시하면 잘못된 신호가 됨.

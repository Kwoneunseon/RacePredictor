2. 단계별 설명

데이터 수집

  • library/collector_*.py — 말/기수/조교사/경주/경주결과/구간기록, 공공데이터포털 API
  • library/scraper_*.py — 배당/마체중, KRA 웹 스크래핑

전처리 · 피처 엔지니어링

  • core/preprocessor.py — 라벨 인코딩 등 학습 전처리
  • core/feature_builder.py — DB에서 피처를 모아 DataFrame으로 변환
  • core/history_rebuilder.py — horse_race_history 테이블 재구성
  • core/race_filter.py — 베팅 대상 경주 필터(거리/등급/두수)

학습 · 캘리브레이션

  • core/trainer.py — XGBoost/LightGBM top3 분류기+ranker 학습, isotonic 캘리브레이션
  • core/model_manager.py — 학습된 모델 저장/로드

확률 모델

  • core/rank_distribution.py — Harville(Plackett-Luce) 방식으로 top3/복연승 확률 유도

예측

  • core/predictor.py — 오늘자 경주 예측 실행, 카카오톡 메시지 포맷 생성

베팅

  • core/ev_calculator.py — EV(기대값)/켈리 비율 계산
  • core/odds_collector.py — 실시간 배당 스크래핑(실패 시 DB 중앙값 fallback)
  • core/investor.py — 베팅 판단·기록(betting_records 저장)과 결과 정산

리포트

  • core/prediction_report.py — 예측 결과 HTML 리포트 생성
  • scripts/feature_importance_report.py — 변수 중요도 HTML 리포트(학습 시마다 갱신)

실행 진입점

  • main.py — --mode {train,predict,update-results,tune} CLI
  • scheduler.py — APScheduler: 시간별/평일 06:00 데이터 수집, 매일 10:00 예측+카카오톡 전송
